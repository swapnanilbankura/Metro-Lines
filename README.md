# Metro Line Shortest Path Finder

The **Metro Line Shortest Path Finder** is a C++ application that calculates the shortest route between metro stations using **Dijkstra's algorithm**. It helps users determine the most efficient path to reach their destination in the least amount of time.

## 🔹 Features

✅ **Shortest Path Calculation** – Uses **Dijkstra's algorithm** to find the optimal metro route.  
✅ **User Authentication** – Provides **Login and Signup** functionality.  
✅ **Interactive Menu** – Users can select their starting and destination metro stations.  
✅ **Real-Time Distance Calculation** – Displays the total distance between stations.  
✅ **Voice Output Support** – Uses `espeak` for an audible welcome message (Linux/macOS).  

## 🔹 Tech Stack

- **Language:** C++  
- **Algorithm:** Dijkstra’s Algorithm  
- **File Handling:** Used for login/signup system  

## 🔹 How It Works

1. **User Authentication** – The user must **login** or **sign up** to access the metro path finder.  
2. **Station Selection** – The user selects the **source** and **destination** metro stations.  
3. **Shortest Path Calculation** – The program applies **Dijkstra's algorithm** to determine the optimal path.  
4. **Route & Distance Display** – The shortest metro route and total distance are displayed.
